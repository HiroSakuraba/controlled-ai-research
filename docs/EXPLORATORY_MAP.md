# Exploratory map

## Established inside the finite prototype

- State-bound, single-use permits prevent the listed replay and payload attacks.
- The receiver fixture deduplicates recovery by nonce; a disagreement remains in
  the dispatch journal for reconciliation.
- The hidden-task custody service controls task identity and acceptance records.
- The finite sampler’s shared amplification budget is checked with exact rational arithmetic.
- Specified monitor channels are complementary on the constructed attack suite.

## Ready for a first funded model run

- A closed-loop episode runner with signed logs, fixed fixture splits, cost
  accounting, and an explicit attacker-development budget.
- Versioned actor and monitor prompts with tested hashes.
- Provider adapter interfaces that are disabled until their live wire formats are
  validated and a paid API is deliberately enabled.

## Requires a model API and a preregistered comparison

- Actor, monitor, attacker, and trusted-replacement comparisons across providers.
- Measured episode harm, usefulness, refusals, parse failures, latency, and cost.
- Cost-matched attack development and held-out evaluation fixtures.
- A reference audit when the reference process itself is a model.

## Deferred research branches

- Latent-dynamics measurements: only for architectures exposing the relevant
  recurrent state, and only as difficulty signals that trigger another check.
- Learned monitors: require calibration on attacks and hard honest work before
  treating scores as interventions.
- Production custody: public-key signing, separate operating-system identities,
  authenticated handoff import, and external-effect reconciliation.
